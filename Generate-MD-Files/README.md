## How these were found

- Ran `CI=true npx react-scripts build` and `CI=true npx react-scripts test --watchAll=false` to reproduce CI-mode failures locally.
- Read every file in `src/components/`, `src/utils/`, and `src/App.js` and traced prop/data flow between them (e.g. what `ActionBar` expects vs. what `App.js` passes; what `OutputViewer` can render vs. what `App.js`'s live error state actually contains).
- Cross-checked against this repo's own conventions (`.claude/agents/react-developer.md`, `.claude/agents/react-testing.md`).
- For issue 7, probed this project's actual `jsonlint-mod` dependency directly with 20 broken-JSON samples to capture real parser output before designing the fix.

All 7 issues are fixed and verified: `CI=true npm run build` compiles cleanly, and `CI=true npm test` passes 26/26 (5 in `App.test.js`, 21 in `src/utils/jsonUtils.test.js` — one per broken-JSON sample from issue 7).
